# v3.0 白皮书草案发布说明

## 当前状态

`DRAFT / NOT FROZEN`。本草案用于收集 2026 年 Java bridge Runtime、MCP 工具、模型生命周期、解释证据和治理能力升级后的公开文档需求。它不改变 v1.0/v2.0 的冻结内容，也不授权下游把候选能力当作 GA。

## 本轮纳入评审的主题

- Runtime Launcher 与 `/readyz`、capabilities 探测；
- datasource registry、diagnostics 和 namespace binding；
- Bundle 注册、model validate/refresh 与 catalog generation；
- `dataset.list_models`、`dataset.explain_query`、Compose 和拆分后的图表导出工具；
- authoring workspace、immutable artifact、release package、promotion、rollback 和 recovery；
- 管理认证、opaque Authorization、审计、解释证据和 AI Provider 可选化。
